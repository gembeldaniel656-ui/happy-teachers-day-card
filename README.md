# 🎓 Happy Teacher's Day Card

Kartu ucapan interaktif Hari Guru yang elegan, terinspirasi dari konsep warna & animasi soft pastel.

## Fitur

- **5 halaman** dengan transisi halus
  1. Amplop 3D yang bisa dibuka
  2. Puisi / sastra
  3. "Song for youuu" + vinyl animasi + lirik *You Are My Sunshine*
  4. Ucapan terima kasih
  5. Closing "Love youuu"
- Backsound *You Are My Sunshine* (loop, volume rendah)
- SFX klik
- Tombol **Back** di kiri bawah
- Audio otomatis berhenti saat tab ditutup / halaman ditinggalkan
- Particle emojis yang mengambang
- Responsif untuk mobile

## Cara menjalankan

1. Upload file audio ke folder `assets/`:
   - `you are my sunshine.mp3`
   - `sfx_click.mp3`
2. Buka `index.html` di browser, atau deploy ke GitHub Pages.

```bash
# serve lokal
npx serve .
```
